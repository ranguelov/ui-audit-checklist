# Чек-лист живой проверки — ui-audit-pro

Страница для ручной проверки интерфейса в конце сессии разработки: пункты
«что и как посмотреть», три ответа на каждый (работает / не так / пропустил),
поле для своих слов и поле для строк из журнала приложения. В конце страница
собирает отчёт в Markdown и JSON.

Всё хранится в браузере и на диске. Никаких серверов, аналитики и запросов
наружу: открывается как обычный файл и работает офлайн.

Данных клиентов здесь нет и быть не может — публикация проверяется заслоном в
`scripts/publish-audit.sh` основного репозитория и отказывается, если имя
клиента или хеш подписи экрана попал в текст.
